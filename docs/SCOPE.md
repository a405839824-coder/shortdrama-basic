# Public basic edition scope

Shortdrama Basic 0.1.0 is a small, independently runnable utility. Its public
source includes project records, verbatim source-text storage, a generic
storyboard table, optimistic revision checks, Excel export, local MCP tools,
installation scripts, synthetic examples and tests.

The basic edition does not contain proprietary storyboard rules, generation
prompts, specialist review/repair strategies, private knowledge bases, customer
material, service credentials, or the history of a private implementation.
Those components are maintained separately and are not needed to run this edition.

The public skill explains only the basic tool interface. The sample table and
export format are generic and do not reproduce a private production template.
Source IDs provide record references; they do not certify source fidelity or
semantic correctness. Revision checks protect edits; they are not an archive.

This edition has its own version, database name and environment variable.
It does not import or migrate another edition's projects. MIT applies to the
software distributed here, not to separate private software or user content.

The repository is intended to be published as a fresh source tree. Do not attach
unrelated Git history, deployment files, account configurations or private tests.
The source packager uses an explicit file list; adding a file to that list is a
release-scope decision and should be reviewed.
